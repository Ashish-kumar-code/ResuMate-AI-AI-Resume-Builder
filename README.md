# ResuMate AI – AI Resume Builder

ResuMate AI is a full-stack AI-powered resume builder that helps users create, manage, and improve professional resumes using intelligent suggestions. The platform is designed to follow modern hiring standards and generate ATS-friendly resume content through a clean and intuitive interface.

---

## 🔗 Live Demo

Frontend (Vercel): https://resu-mate-ai-theta.vercel.app  
Backend (Render): https://resumate-ai-a0q8.onrender.com

⚠️ Note: The backend is hosted on Render’s free tier, so the first request may take 20–40 seconds to respond.

---

## 🚀 Features

- Secure user authentication using JWT
- Create, edit, and manage multiple resumes
- AI-assisted resume content generation
- Structured resume sections (Education, Skills, Experience, Projects)
- AI-enhanced wording for professional impact
- RESTful API-based backend
- Responsive and modern user interface
- Production-ready deployment

---

## 🤖 AI Capabilities

- Generates resume content based on user input
- Improves clarity and professionalism of resume descriptions
- Enhances experience and project statements
- Helps optimize resumes for ATS-friendly language

---

## 🎯 Problem & Solution

Problem:  
Creating a professional resume is time-consuming and difficult, especially for students and early-career professionals who struggle with wording, structure, and impact.

Solution:  
ResuMate AI simplifies resume creation by combining structured resume building with AI-powered suggestions, enabling users to create high-quality resumes efficiently and confidently.

## 🧪 Local Development Setup

Clone the repository:
git clone https://github.com/iprabhakersingh/ResuMate-AI.git

cd ResuMate-AI  

Start backend:
cd server  
npm install  
npm run server  

Start frontend:
cd client  
npm install  
npm run dev
